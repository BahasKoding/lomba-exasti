# Bug Report Standard

```text
Bug ID:
Title:
Module / Feature:
Severity:
Environment:
Related Test Case:
Preconditions:
Steps:
1.
2.
3.
Expected Result:
Actual Result:
Evidence:
Status:
Notes:
```

An automation failure may be used as a draft bug, but `Automation FAIL` does not automatically mean `Application BUG`. QA must reproduce and verify the issue before confirming it.
