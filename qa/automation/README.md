# Playwright Automation

Playwright Test is configured with this directory as `testDir`. Keep coverage aligned with implemented behavior and favor deterministic UI, API, integration, and regression checks.

Current automation is limited to one stable storefront rendering smoke check. Browser binaries are intentionally not installed as part of this foundation setup.

Commands:

- `npm run qa:test` — run Playwright tests
- `npm run qa:test:list` — discover tests without executing a browser
- `npm run qa:report` — open the latest HTML report
