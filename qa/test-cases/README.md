# Test Case Standard

Use this template; do not create cases for unimplemented behavior.

```text
Test Case ID:
Module:
Feature:
Title:
Preconditions:
Steps:
1.
2.
3.
Expected Result:
Priority:
Type: Positive | Negative | Edge
Automation: Yes | No | Candidate
Notes:
```

Rules:

- Keep titles short.
- Keep expected results concise, measurable, and deterministic where possible.
- Avoid duplicate scenarios.
- Align frontend and backend validation coverage for the same implemented feature.
- Use only Positive, Negative, or Edge for `Type`.
- Use only Yes, No, or Candidate for `Automation`.
